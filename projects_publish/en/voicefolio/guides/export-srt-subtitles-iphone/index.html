How to export SRT subtitles from video or audio on iPhone

An SRT file stores caption text with start and end times. VoiceFolio can transcribe a recording on your iPhone and export those timed segments as a separate subtitle file for a compatible editor or player.

Before you start

  • An iPhone with iOS 17 or later and VoiceFolio, plus an audio or video file you can import.
  • A downloaded speech model suitable for the source language. Initial model downloads need a connection; transcription can then work offline.
  • Transcription uses your free allowance or Pro access. PDF export and speaker separation are Pro features; an ordinary SRT export does not require those features.
01

Import your video or audio file

Choose Import from Files for an existing audio or video file, or Import video from Photos for a video in your photo library. VoiceFolio also accepts recordings shared from Voice Memos. Wait for import to finish.

For a video from a social platform, first obtain a local copy that you can use. VoiceFolio works with imported files and does not download a video from a pasted social-media link.

02

Create a timestamped transcript

Open the project, confirm the spoken Source language where needed, and choose Start Transcription if it has not started automatically. Transcribe the original speech before preparing a translation or summary.

The transcript provides the timed segments used in SRT export. A summary or a plain paragraph of text does not provide the same caption timing.

03

Proofread while listening

Replay the recording and check the transcript, especially names, numbers and short phrases. Use sentence timestamps to find the matching audio. Correct the wording before exporting, then check the exported captions in the editor or player where you plan to use them.

If you trim or rearrange the media after making subtitles, the old timestamps may no longer match. Export against the version of the recording you intend to caption.

04

Choose SRT in Export

Open the project’s Export panel. Under Format, select SRT; under Content, choose Transcript. SRT includes timing automatically, so a separate text timestamp toggle is not needed.

Choose VTT instead if your destination asks for WebVTT. For two-language captions, Bilingual Subtitles becomes available when the project already has a translation. Creating that translation is a separate step.

05

Save the .srt file and test it

Choose Export & Share and save the file to Files or send it to your editing app. Confirm the filename ends in .srt. Import it alongside the same recording in a compatible editor or player, and check the beginning, middle and end for timing and readability.

This produces a subtitle file alongside your media. It does not burn visible text into the video or export a newly captioned movie. Use an editor that supports SRT import if you need that final video.

Common questions

The export is empty

Confirm that speech transcription has finished and the project contains nonempty timed segments. Export the Transcript content rather than a summary.

Bilingual Subtitles is unavailable

The project needs a saved translation before that content option appears. A single-language SRT remains available from the original transcript.

Your player does not show captions

Check that the app supports external SRT subtitles, that it loaded the subtitle file, and that the file belongs to the same media version. Some destinations require you to import the file explicitly.
