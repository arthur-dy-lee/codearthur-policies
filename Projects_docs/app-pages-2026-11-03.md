## Implementation

- Shared CSS is `projects_publish/en/assets/app-pages.css`; no JavaScript, external fonts or analytics are required.
- Every product page has a title, description, canonical URL, Open Graph metadata, its own favicon, App Store link, real screenshots, practical details, native FAQ disclosures and related app links.
- JSON-LD contains SoftwareApplication, WebPage and BreadcrumbList data. It deliberately omits unsupported prices and ratings; it does not claim Google rich-result eligibility.
- The homepage’s existing Google ownership verification tag is retained.
- No unrelated policy, license or source image files were changed. Existing local untracked artwork was not included.

## Validation before publication

- HTML structure, internal file/fragment links, download IDs, image dimensions and JSON-LD parsing checked for nine pages; sitemap XML has nine unique matching canonical URLs.
- Browser checks completed in Chrome at actual CSS widths 1672, 375 and 288 pixels: no document horizontal overflow, one h1 per page and no broken eager images.
- FAQ pointer and keyboard toggling checked. Viewport override reset afterward.
- Real-device iOS/macOS Safari testing is outside this verification. Publication and HTTP availability do not establish Google indexing.
