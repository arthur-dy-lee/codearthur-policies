Whisper — OpenAI

Speech recognition and speech translation models, including Base, Small, Medium, and Large V3 Turbo. OpenAI's Whisper repository releases its code and model weights under the MIT License. The Large V3 Turbo model card also identifies MIT as its license.

Whisper Large V3 — Additional Model Notice

The original Large V3 model card identifies Apache License 2.0, while the OpenAI Whisper repository states that its code and model weights are MIT licensed. Both license texts are retained here for this optional model variant.

Paraformer INT8 — Alibaba DAMO Academy

Optional Chinese speech recognition model. The original Paraformer-large model is published by Alibaba DAMO Academy through ModelScope. The INT8 ONNX model and vocabulary distributed by csukuangfj are converted from iic/speech_paraformer-large_asr_nat-zh-cn-16k-common-vocab8358-tensorflow1, tag v1.1.9.

Attribution: Alibaba DAMO Academy speech team; ONNX conversion distributed by csukuangfj / the sherpa-onnx project.
Model license: Apache License 2.0 — full text below, as identified by the original ModelScope model. This model license is separate from the license of the FunASR code repository.

Conversion: csukuangfj/sherpa-onnx-paraformer-zh-2024-03-09, revision 906992d326ebf0c5171cde675aa0902be9e5bc6c. VoiceFolio downloads model.int8.onnx and tokens.txt from this revision. The distributed weights are an ONNX conversion with INT8 quantization of the upstream model.

  • Original Paraformer-large model and license
  • Original v1.1.9 model card with Apache 2.0 declaration
  • Pinned ONNX / INT8 model files · Conversion provenance

Qwen3-ASR 0.6B — Qwen Team / Alibaba Cloud

Optional multilingual speech recognition model used by PromptTempo through the shared sherpa-onnx runtime. The original model weights and tokenizer are published by the Qwen team. The app uses a third-party ONNX / INT8 conversion by Wasser1462 / zengshuishui, distributed on Hugging Face by csukuangfj2 and on ModelScope by zengshuishui.

Attribution: Qwen Team / Alibaba Cloud; ONNX conversion by Wasser1462 / zengshuishui; Hugging Face distribution by csukuangfj2.
Model license: Apache License 2.0 — full text below, as identified by the original Qwen model.

Base model: Qwen/Qwen3-ASR-0.6B.
Conversion: csukuangfj2/sherpa-onnx-qwen3-asr-0.6B-int8-2026-03-25, revision 68818b2313fe77bd06f6a7c5068ff3ef59d02b8a. The model is converted to ONNX with INT8 quantization; this is not an official Qwen ONNX release.

  • Original Qwen3-ASR 0.6B model card and Apache 2.0 declaration · Official implementation license
  • Pinned ONNX / INT8 model files · Conversion provenance
  • Third-party ONNX exporter · ModelScope conversion source

Qwen3-ASR 1.7B — Qwen Team / Alibaba Cloud

Optional multilingual speech recognition model used by apps on macOS. The original model weights and tokenizer are published by the Qwen team. Current downloads use a third-party ONNX / INT8 conversion by Wasser1462 / zengshuishui, mirrored by ilmina. Existing installations and offline bundles may retain the independent mixed-precision INT8 / FP32 ONNX conversion distributed by solavr for sherpa-onnx.

Attribution: Qwen Team / Alibaba Cloud; ONNX conversion by Wasser1462 / zengshuishui, mirrored by ilmina; legacy independent ONNX conversion distributed by solavr.
Model license: Apache License 2.0 — full text below, as identified by the original Qwen model. The official implementation and legacy independent exporter also identify Apache 2.0. The legacy conversion's NOTICE is retained below.

Current INT8 distribution: ilmina/qwen3-asr-1.7b-sherpa-onnx, revision 66fb5ea2d4d1682ff8a663bf7e788913604996a0, with matching model files available from zengshuishui/Qwen3-ASR-onnx on ModelScope.

Legacy base model: Qwen/Qwen3-ASR-1.7B, revision 7278e1e70fe206f11671096ffdd38061171dd6e5.
Legacy mixed-precision conversion: solavr/sherpa-onnx-qwen3-asr-1.7B-int8, revision 455608654fe097e55cc9ecac65fd83e53d2347c1.

The legacy conversion exports the original BF16 weights to ONNX, with an FP32 convolutional frontend, an INT8 audio encoder, and a mixed INT8 / FP32 decoder with external weight data. Decoder attention projections remain FP32, and tokenizer files are copied unchanged. These third-party conversions are not official Qwen or k2-fsa releases.

  • Pinned current ONNX / INT8 model files · ModelScope conversion source · Third-party ONNX exporter
  • Original Qwen3-ASR 1.7B model card and Apache 2.0 declaration
  • Official model implementation used for export
  • Pinned mixed-precision ONNX model files · Conversion provenance
  • Conversion license · Conversion NOTICE · Conversion modifications

Underdog Bark 3.0 Pro / Plus — Conway Research

Optional English speech recognition models published by Conway Research. The apps use the official Core ML model files. Bark derives from NVIDIA's Parakeet TDT 0.6B v3 through Moondream's Parakeet Ultra, with post-training and compression by Conway Research.

Attribution: Conway Research; Copyright (c) NVIDIA Corporation; Copyright (c) Moondream.
License: Creative Commons Attribution 4.0 International (CC BY 4.0) — full text below. The upstream attribution and modification notices are retained separately for Pro and Plus.

Pro: ConwayResearch/Underdog-Bark-3.0-Pro, revision 4b5c51e04aa8d16dda9ecdff71bc29f7360149e4.
Plus: ConwayResearch/Underdog-Bark-3.0-Plus, revision d4fab2f8b95681e5ad3cfb4e8c5f4e0c009b3deb.

App adaptations: The Plus frontend and TDT decoder are adapted from Conway Research's coreml/ane/bark_coreml.py to native Swift / Accelerate, with bounded audio windows, Core ML loading, and verified downloads. The distributed model weights are not modified by the apps. Pro uses the FluidAudio runtime, whose software license is listed separately below.

  • Pro model card · Pinned Pro Core ML files · Pro license · Pro NOTICE
  • Plus model card · Pinned Plus Core ML files · Plus license · Plus NOTICE
  • NVIDIA Parakeet TDT 0.6B v3 · Moondream Parakeet Ultra
  • CC BY 4.0 license · Official legal code

2. Speech Runtime Libraries

WhisperKit — Argmax

WhisperKit provides on-device speech recognition using Core ML. Argmax also distributes converted Whisper models in the WhisperKit Core ML model repository, whose model card identifies the MIT License.

Copyright: Copyright (c) 2024 argmax, inc.
License: MIT — full notice below.

  • WhisperKit source repository
  • WhisperKit 0.10.1 license
  • WhisperKit Core ML model repository

sherpa-onnx — k2-fsa

On-device speech recognition runtime used for Paraformer INT8 and Qwen3-ASR 0.6B / 1.7B. VoiceFolio uses the 1.13.8 binary distribution packaged by willwade/sherpa-onnx-spm, with its own local Swift wrapper.

Attribution: k2-fsa and sherpa-onnx contributors. Individual source files retain their respective copyright notices.
License: Apache License 2.0 — full text below.

  • sherpa-onnx 1.13.8 source · Upstream Apache 2.0 license
  • Binary distribution

FluidAudio — Fluid Inference

Swift audio inference library used to run the official Bark 3.0 Pro Core ML pipeline, including TDT decoding. The shared Bark package pins revision a00964e1aa8eff99c4bce80bc9c8ff2d4dd1568d.

Attribution: Fluid Inference and FluidAudio contributors. Individual source files retain their respective copyright notices.
Software license: Apache License 2.0 — full text below. This runtime license is separate from the Bark models' CC BY 4.0 license.

  • Pinned FluidAudio source · Upstream Apache 2.0 license
